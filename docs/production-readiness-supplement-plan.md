# 운영 준비도 보완 계획 (Supplement)

작성일: 2026-02-19  
기준 문서: `docs/production-readiness-checklist.md`

## 목적

- 현재 체크리스트 미충족 항목을 단기/중기로 나눠 빠르게 보완한다.
- "설정 존재"가 아니라 "실제 동작 검증"까지 완료 상태로 만든다.

## 현재 요약

- 필수 충족률: 약 62%
- 권장 충족률: 약 14%
- 목표: 필수 100% + 권장 70% 이상

## P0 (즉시, 1주 내)

### 1) GitHub Required Checks 강제 적용

- 할 일
  - `main` 브랜치 보호 규칙에 `lint`, `typecheck`, `test`, `build`를 Required checks로 고정
  - 관리자도 우회 불가(enforce admins) 유지
- 완료 기준
  - PR에서 4개 체크 미통과 시 merge 불가
  - `gh api .../branches/main/protection` 조회 결과에 4개 context 명시
- 검증
  - `docs/runbooks/github-required-checks.md` 절차로 적용/조회 로그 남기기

### 2) Web 핵심 E2E 2개 추가

- 할 일
  - 시나리오 A: 업로드 -> 인식 -> 후보 선택 -> 가격 조회
  - 시나리오 B: OCR 실패 -> 수동 검색 -> 가격 조회
- 완료 기준
  - CI에서 E2E 테스트가 자동 실행되고 안정적으로 통과
  - 실패 시 재현 가능한 스크린샷/로그 수집
- 검증
  - PR CI 아티팩트에 테스트 리포트 첨부

### 3) 대시보드/알람 실제 연결

- 할 일
  - 관측 지표 대시보드 구축: 성공률, 5xx, p95/p99, OCR confidence, provider 실패율, cache hit/miss
  - 알람 룰 구성: 5xx 급증, provider 실패율 급증, DB/Redis 장애
- 완료 기준
  - 대시보드 URL 공유
  - 알람 채널(슬랙/이메일) 연결
  - 의도적 실패 1회로 알람 발화 확인
- 검증
  - `docs/observability-baseline.md`의 완료 체크박스 4개 전부 체크

### 4) 스테이징 리허설 1회 수행/기록

- 할 일
  - 스테이징 DB 마이그레이션 + 롤백 리허설 1회 수행
  - 리허설 기록 템플릿(시간, 결과, 후속조치) 작성
- 완료 기준
  - Go/No-Go 기준 충족 기록 존재
  - RTO 목표(60분) 내 복구 성공 기록
- 검증
  - `docs/runbooks/staging-migration-rehearsal.md`에 실제 실행 이력 추가

## P1 (단기, 2~3주)

### 5) API 보안 헤더 강화

- 할 일
  - Helmet 또는 동등 보안 헤더 정책 적용
  - CORS 허용 도메인 최소화 정책 문서화
- 완료 기준
  - 응답 헤더에 필수 보안 헤더 포함
  - 운영 환경에서 와일드카드 CORS 미사용
- 검증
  - `curl -I`로 헤더 확인 결과 첨부

### 6) 가격 스냅샷 데이터 정책 확정

- 할 일
  - 보존기간, 중복 판단 기준, 정합성 점검 규칙 문서화
  - 운영 배치/정리 정책(예: 오래된 snapshot 아카이빙) 정의
- 완료 기준
  - 정책 문서 1개 + 운영 실행 절차 1개 존재
- 검증
  - 샘플 데이터로 정책 적용 전/후 row count와 무결성 점검 결과 기록

### 7) DB 성능 검증 (핵심 쿼리 explain)

- 할 일
  - `/cards/search`, `/cards/:id/prices` 관련 핵심 쿼리 추출
  - 인덱스 적합성 검토 및 필요 시 인덱스 추가
- 완료 기준
  - 핵심 쿼리 explain 결과 문서화
  - 병목 쿼리 0건 또는 개선 내역 기록
- 검증
  - explain 결과 스냅샷 첨부

### 8) 부하 테스트 + SLO 수립

- 할 일
  - API p95/p99 SLO 정의
  - 목표 트래픽 기준 부하 테스트 시나리오 수행
- 완료 기준
  - SLO 문서화
  - 부하 테스트 리포트 1회 이상 확보
- 검증
  - 기준 초과 구간에 대한 개선 액션 등록

- 완료 기준
  - 비용 알람 활성화
  - 보안/컴플라이언스 문서 최신화
